# Hallo-Skill

1. Lies die README bzw. die wichtigsten Dateien im Projektwurzelverzeichnis.
2. Antworte auf Deutsch mit einer kurzen Begrüßung.
3. Fasse den Zweck des Projekts in zwei bis drei Sätzen zusammen.

Ersetze diese Anleitung durch deinen eigenen Arbeitsablauf.
