Begrüße $ARGUMENTS (oder den Nutzer, falls kein Name angegeben ist) auf Deutsch.
Fasse danach in höchstens drei Sätzen zusammen, woran im aktuellen Repository
gearbeitet wird (schau dir dazu `git status` und die letzten Commits an).
